# Security Policy

## Supported versions

| Package | Supported |
| --- | --- |
| Latest minor release of each package | Yes |
| Older versions | No |

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub's "Report a vulnerability" (private security advisories) on this repository. If that is unavailable, email [security@friendzone.dev](mailto:security@friendzone.dev).

Include the affected package and version, steps to reproduce, and impact. You will get an acknowledgement within 7 days and a status update within 30 days. Fixed issues are disclosed in the release notes and a GitHub security advisory, crediting the reporter unless they prefer otherwise.

## Scope

In scope: anything that could expose screen content, API keys, saved output, audio, or let another process control the suite. See [threat model](docs/security/threat-model.md).
