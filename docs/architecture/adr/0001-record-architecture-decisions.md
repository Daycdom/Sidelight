# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-04
- Deciders: Dominic

## Context and problem

The suite is built by one developer with AI coding help over many months. Reasons behind early choices are easy to forget, and AI assistants need written context.

## Decision

Record every significant architecture decision as an ADR in `docs/architecture/adr/`, using the MADR format.

## Consequences

- Good: decisions are searchable and can be given to AI tools as context.
- Bad: small writing overhead per decision.
